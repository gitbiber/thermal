# Pico 2 Wärmebildkamera (WebUSB)

Mobile Wärmebildkamera auf Basis eines Raspberry Pi Pico 2 mit MLX90640-Sensor.
Die Anzeige läuft komplett im Browser (Google Chrome auf Android) über WebUSB —
keine native App, kein Treiber, kein zusätzliches Netzteil. Das Smartphone
versorgt den Pico per USB-OTG und zeigt das Wärmebild als Web-App an.

Entwickelt für die Suche nach Wärmequellen im Freien (Igel, Katze, Motor),
funktioniert aber genauso für Haustechnik, Elektronik-Diagnose oder
Isolationsprüfung.
